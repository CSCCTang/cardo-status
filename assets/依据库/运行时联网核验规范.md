# 运行时联网核验规范

**适用范围**：使用 `依据库.json` 生成《项目现状分析报告》《项目投资决策建议书》“编制依据”章节时的联网复核与断网降级。
**版本**：1.0 ｜ 2026-11-15
**配套文件**：`依据库.json`（离线基线）、`核验任务.json`（逐条核验任务）、`核验记录.md`（人工查证底稿）

---

## 1. 定位与基本原则

1. **离线基线不是唯一来源**。`依据库.json` 是断网时仍可出报告的底稿；每次生成报告，都应在条件允许时联网复核。
2. **联网复核不改变“不许编造”底线**。复核只能“确认、更新、标废”，不能因为查不到就补一个像样的文号或日期。
3. **未复核必须显性化**。凡是未联网复核的条目，报告中必须有可识别的标注，不能把“未复核”呈现成“已核实”。
4. **降级不阻断出报告**。联网失败时照常出报告，但依据表按第 6 节降级写法呈现。
5. **写回留痕**。复核结果写回库文件时，保留原核验记录，不覆盖历史。

### 1.1 强制顺序（硬规则，不得颠倒）

任何一条依据进入报告前，按下列唯一顺序处理：

| 顺序 | 动作 | 判定条件 | 落地要求 |
| --- | --- | --- | --- |
| ① | **先联网核验** | 只要能联网，就必须对拟引用条目逐条检索官方原文 | 命中官方页面并按第 3 节比对；`复核方式` 记“在线原文／在线检索” |
| ② | **核不到才登记待确认** | 官方站点查无原文、无文号、无有效页 | `核验状态` 记“待核实”；**必须同时登记三样**：已查来源（站点域名＋具体页面URL）、检索关键词、查询时间（YYYY-MM-DD） |
| ③ | **断网才退基线库** | 确认无网络或检索接口不可用（而非“没搜到”） | `复核方式` 记“离线基线”，`联网核验结果` 记“未能联网”，报告中标注“未联网复核” |

三条硬性禁止：
- **禁止跳过①直接写“待核实”**。没查过就登记待确认，等同伪造核验过程。
- **禁止只写“待核实”不写查证痕迹**。待确认条目若缺“已查来源／检索关键词／查询时间”三项，视为登记不合格，不得进入依据表。
- **禁止把“搜不到”当成“断网”**。搜不到属于②，断网属于③，两者标注不同、后果不同。

> 判定口诀：**能上网就必须查；查不到记待确认并留痕；只有真的断网才退回基线库。**

---

## 2. 什么时候核验

| 时机 | 要求 |
| --- | --- |
| 每次生成报告“编制依据”章节前 | 必须对本章拟引用的每条依据执行核验 |
| 距上次核验超过 30 天 | 视为缓存过期，必须重新核验 |
| 引用“有效期5年”类文件 | 无论缓存是否过期，都必须核验效力状态 |
| 引用“待核实”条目 | 必须尝试取得原文；仍取不到则按待核实写法呈现 |
| 报告发布前（终稿） | 对已引用条目做一次抽查，比例不低于 30% |

## 3. 查什么：逐条比对字段

按 `核验任务.json` 的 `检索关键词` 检索，命中官方页面后比对下列字段。全部一致才算“一致”。

### 3.1 政策文件

| 字段 | 比对要求 | 不一致时的处理 |
| --- | --- | --- |
| 名称 | 全称逐字比对，含书名号、部门并列顺序 | 以官方现名称为准，更新库 |
| 文号 | 年度、序号、机关代字逐字比对（如“建科”≠“建办科”） | 以官方原文为准，旧写法写入备注 |
| 发布机关 | 联合发文须核对全部机关 | 更新库，报告不得简写为单一机关 |
| 发布日期 | 成文日期与网站发布日期分别记录 | 报告采用网站发布日期，备注成文日期 |
| 施行日期 | 核对是否“自印发之日起”或有具体日期 | 更新库 |
| 效力状态 | 是否标注“有效／失效／废止”，是否被新文件替代 | 见第 4 节 |

### 3.2 技术标准

| 字段 | 比对要求 |
| --- | --- |
| 标准名称 | 逐字比对，注意“规范／标准／导则”差异 |
| 标准号 | 编号、年份、推荐性“/T”逐字比对 |
| 发布／实施日期 | 以标准公告或标准文本封面为准 |
| 替代关系 | 是否声明“原标准同时废止” |
| 现行性 | 是否被修订版替代（查标准公告、全国标准信息公共服务平台） |

### 3.3 编制办法

| 字段 | 比对要求 |
| --- | --- |
| 名称、文号、发布机关 | 同政策文件 |
| 修订情况 | 是否发布修订版或征求意见稿 |
| 适用范围 | 是否仍适用于本项目类型 |

## 4. 发现变化怎么处置

| 情形 | 判定 | 处置 |
| --- | --- | --- |
| 名称、文号、日期与库一致 | 一致 | 正常引用；更新 `核验时间` |
| 文号或日期变更（如重新发布） | 有更新 | 以官方新文本为准，更新库中名称／文号／日期，旧值写入 `备注`；报告使用新值 |
| 文件被明确废止或被新文件替代 | 已废止 | **停止引用被废止文件**；若替代文件已在库中，改用替代文件；若不在库中，先补录再引用 |
| 文件标注“失效”但未给替代文件 | 已废止 | 不引用该文件；在报告依据表中删除；如该依据支撑的结论无法替代，转为定性表述并注明“政策依据更新中” |
| 检索到同名文件但机关／层级不同 | 不能判定 | 按“待核实”处理，报告中只作方向性引用 |
| 官方页面无法打开、检索无结果 | 未能联网 | 见第 5 节降级 |
| 仅在转载站、文库、自媒体命中 | 未能联网 | 不作为定稿依据；有官方页面才可判“一致” |

**替代关系处理规则**

1. 替代文件已核实：报告中直接引用新文件，不并列引用旧文件。
2. 替代关系只在一方文件中出现、另一方未见：库中记 `替代关系` 为“待确认”，报告避免使用“依据××（已废止）”的表述。
3. 新旧文件并行（如省技术导则与省地方标准）：按“专项优先、层级优先”选用，无法判断时并列引用并注明关系待确认。

## 5. 联网失败时的降级

### 5.1 降级判定

以下任一情况视为“未能联网”（仅限**技术性不可达**）：
- 无网络，或检索接口／浏览器不可用；
- 网络可达但目标官方站点持续超时、502／503，且重试后仍无法打开；
- 官方页面存在但正文为空白、图片不可读，导致关键字段完全无法辨认。

**不属于“未能联网”、应按第 1.1 节②登记待确认的情形**：
- 能联网、检索正常，只是官方站点查不到该文件（“搜不到”≠“断网”）；
- 只检索到转载站、文库、自媒体，未命中官方域名；
- 命中官方页面但该页不载文号／日期（属“核不到”，记待核实并写明缺什么）。

### 5.2 降级动作

1. **继续出报告**，不因核验失败中断。
2. 使用 `依据库.json` 的离线基线值，`复核方式` 记为“离线基线”，`联网核验结果` 记为“未能联网”。
3. 报告中该条依据加“未联网复核”标识（见 6.2）。
4. 在报告末尾“编制说明”或内部件《依据核对表》中列出未复核条目清单。
5. 不因降级而删除依据，也不因降级而把“待核实”升格为“已核实”。

### 5.3 降级后禁止事项

- 禁止静默使用离线值而不标注；
- 禁止用记忆中的文号替代库中值；
- 禁止把“待核实”条目写成有文号的正式依据；
- 禁止因联网失败而编造“已核对”结论。

## 6. 报告中如何呈现

### 6.1 正常（已联网复核且一致）

> 依据《国务院办公厅关于全面推进城镇老旧小区改造工作的指导意见》（国办发〔2020〕23号）。

> 技术标准执行《既有建筑鉴定与加固通用规范》（GB 55021-2021）。

### 6.2 未联网复核（使用离线基线）

> 依据《国务院办公厅关于全面推进城镇老旧小区改造工作的指导意见》（国办发〔2020〕23号）；该文号经本地编制依据库离线核对，生成时未联网复核。

表格形式可在“核验方式”列写：`离线基线（未联网复核）`。

### 6.3 待核实条目

> 市级层面参照成都市城镇老旧院落（小区）改造技术导则（试行）的方向性要求；该导则文号与发布日期尚未取得公开原文，本报告不引用其具体条款与指标。

表格形式可在“文号”列写：`待核实`，在“备注”列写：`未取得公开原文，仅作方向性引用`。

### 6.4 已废止／被替代

> 依据《建设工程工程量清单计价标准》（GB/T 50500-2024）；原《建设工程工程量清单计价规范》（GB 50500-2013）已同时废止，不再引用。

### 6.5 禁用写法

| 禁用写法 | 原因 |
| --- | --- |
| “根据国办发〔20XX〕XX号”（文号未经核验） | 文号可能是虚构或过期 |
| “依据国家、省、市有关政策文件”后列一堆无文号名称 | 无法核对，等同凑数 |
| 把“中共中央办公厅、国务院办公厅印发”写成“国办发〔2025〕X号” | 公开文本无文号，属编造 |
| 把已废止标准与新标准并列引用 | 口径冲突 |
| 用“相关政策”“有关规定”替代具体依据 | 空泛，评审不可核 |

## 7. 写回与留痕

1. 核验完成后更新 `依据库.json` 对应条目的：`核验时间`、`复核方式`、`联网核验结果`、`核验来源`、`原文URL`；名称／文号／日期有变化的同步更新，旧值写入 `备注`。
2. `内容指纹` 按“名称+文号+发布日期+可引用要点”重新计算（去空白后拼接，sha256）。
3. 在 `核验记录.md` 末尾按日期追加一行记录：`日期｜条目ID｜结论｜变更内容｜来源URL`。
4. 不删除历史核验记录；不覆盖 `核验记录.md` 中已有的人工查证说明。

---

## 8. 核验优先级

时间有限时按以下顺序核验：

1. 报告中直接写入文号的条目（必须全部核验）；
2. 标注“有效期5年”或临近有效期的文件；
3. 2024年以后发布、可能被修订的标准；
4. 待核实条目（争取取得原文）；
5. 仅作定性引用的政策文件（可抽查）。

---

## 9. 一句话流程

> 读库 → 按任务清单检索官方页 → 六字段比对 → 一致则引用／有更新则改库／已废止则换文件／查不到则降级标注 → 写回核验时间与记录 → 再出报告。
