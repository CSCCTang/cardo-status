# 输入准备（cardo-status）

## 文件清单

| 文件 | 必需 | 形态 |
|---|---|---|
| 项目资料 | 否（建议给） | docx / xlsx / pdf / 图片，批复、规划、立项、会议纪要等 |
| 现状底稿 | 否（建议给） | docx / xlsx，甲方或项目组调研底稿 |
| 分析范围 | 是 | 对话里说明，或按运行时提问答复 |

## 最小样例

本包不附样例材料。最小起步 = 一份现状底稿（docx）+ 一句话说明分析范围。

## 摆放

```
D:\proj\status-01\
  输入文件\批复.pdf
  输入文件\现状底稿.docx
  输入文件\规划资料\xxx.docx        <- 允许子目录
```

## 格式建议

- 扫描件尽量附一份可复制文字的版本；纯图片会走离线识别，识别不可用时只按文件名归类。
- 一个文件一件事，文件名写清来源与时间，报告引用时更好定位。

## 不要放什么

- 与本次范围无关的项目资料。
- 加密或带打开密码的文件（先解密）。
