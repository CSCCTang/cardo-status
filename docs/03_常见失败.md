# 常见失败（cardo-status）

| 看到的提示 | 怎么办 |
|---|---|
| 没有可用材料 | 把 docx / xlsx / pdf 放进工作区 `输入文件\` |
| 还没答复分析范围 | 在对话里说明范围，或按提示逐项答复 |
| 扫描件识别不可用 | 换可复制文字的版本，或接受「按文件名归类」的结论 |
| 报告里某结论标注为推断 | 补一份对应材料后重跑，结论会刷新为实测 |
| 数据缺口清单很长 | 按清单优先级补关键材料即可，不必一次补齐 |
| 工作区被占用 | 确认没有另一个任务在跑同一工作区，稍后重试 |
| 提示工作区越界被拒绝 | 换一个独立空文件夹；或用 `CARDO_WORKSPACE_HOME` 指定默认工作区的根目录 |
| 找不到交付包 | 跑 `python "<技能目录>/scripts/cardo.py" --where` 看实际包目录，或用 `CARDO_HOME` 指向包所在目录 |

环境自检：`python "<技能目录>/scripts/cardo.py" --doctor` 打印交付包、入口、Python、默认工作区与目录架构。
