# 事实抽取口径说明（脚本内置，改口径需同步 extract_facts.py）

本技能的事实抽取规则以常量形式写死在 `scripts/extract_facts.py`，不读取外部 YAML；
本文件用于说明口径，供复核与交接使用。

## 入库条件
1. 数字 + 单位：`NUM_RE` 只认带单位数字（平方米、平方公里、万元、亿元、公里、%、栋、户、人等）。
2. 可核验编号：文号（〔2024〕xx 号）、标准号（GB/T xxxxx、GB xxxxx、xx/T xxxxx）。
3. 段落引文：引文必须能在转储 blocks 中原地匹配；匹配不到不入库。

## 置信度
- `high`：带单位数字、表格单元格数字、可核验编号。
- `medium`：无单位但有明确指向的段落表述（截断 120 字）。
- 冲突：同一 section + phrase + unit 出现多个不同值 → 写入冲突表，全部保留，不取平均、不选一个。

## 覆盖与空库
- 覆盖表按 23 个模板节点统计“是否抽到事实”。
- 事实库为空 → pipeline 阻断（不允许无事实成文）。
- 本技能不改写、不推断、不补数。
