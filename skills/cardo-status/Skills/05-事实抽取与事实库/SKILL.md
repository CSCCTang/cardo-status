# 05 事实抽取与事实库

## 用途
从源报告转储中抽取可核验事实（数字+单位、文号/标准号、段落引文），建立事实库与
覆盖表、冲突表；只抽取，不推断、不改写。

## 单独运行
```powershell
python Skills/05-事实抽取与事实库/scripts/extract_facts.py ^
  --project-dir . ^
  --dump-dir 过程文件/03-模板与源报告转储/源报告转储 ^
  --mapping 过程文件/04-章节映射/章节映射.yaml ^
  --out 过程文件/05-事实抽取与事实库/facts
```

## 输出
- `facts/事实库.json`：`facts[]`（id、值、单位、引文、源段、章节节点）。
- `facts/覆盖表.json`：23 节点中有多少抽到事实。
- `facts/冲突表.json`（若有同指标多值）。
- 若传 `图件清单/分类清单`，可生成“事实缺失”清单供 09 汇总。

## 退出码
0 成功且事实数 >0；1 抽取失败/空库；2 参数错误。

## 规则要点
- 抽取规则以常量形式内置在 `scripts/extract_facts.py`；口径说明见 `规则/事实抽取口径.md`（改口径需同步脚本）。
- 数字必须带单位或可核验编号，裸数字不入库。
- 引文必须能在转储 blocks 中原地匹配；匹配不到不入库。
- 冲突按 `(0, 数字序) / (1, 字符串序)` 稳定排序，不丢记录。
- 事实库为空时 pipeline 直接阻断（不允许“无事实成文”）。
- 来源路径由 pipeline 统一落成工作区相对 posix 路径（`过程文件/…`），不写盘符；回溯表只引用 factId，不复制数值。
