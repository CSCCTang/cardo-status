# 01 建档与材料归集

## 用途
扫描投递区（默认 `输入文件/`），按 `规则/分类规则.yaml` 自动归类；不确定的文件进入待确认清单，
人工确认后落位，并生成项目索引与原件指纹。原件不复制、不移动（dry-run 模式只登记）。

## 单独运行
```powershell
# 1) 分类（只读扫描，写分类清单）
python Skills/01-建档与材料归集/scripts/classify_materials.py ^
  --project-dir . --delivery 输入文件 --out 过程文件/01-建档与材料归集/分类清单

# 2) 人工填写 过程文件/01-建档与材料归集/分类确认.yaml 后落位
python Skills/01-建档与材料归集/scripts/confirm_and_merge.py ^
  --project-dir . ^
  --manifest 过程文件/01-建档与材料归集/分类清单/分类清单.json ^
  --confirm 过程文件/01-建档与材料归集/分类确认.yaml ^
  --rules Skills/01-建档与材料归集/规则/分类规则.yaml ^
  --template ..\提资数据\模板\<模板>.docx --source 输入文件/<源报告>.docx ^
  --project <项目名> --direction 老旧街区^|老旧小区^|老旧厂区 --delivery 输入文件 ^
  --index-out 过程文件/00-总控/项目索引.md ^
  --fingerprint 过程文件/01-建档与材料归集/原件指纹.json
```

## 输入
- 投递区实际文件（只读）。
- `分类规则.yaml`：类别、关键词、阈值、目标目录。
- `分类确认.yaml`：`decisions[].file / category_id / note`。

## 输出
- `分类清单/分类清单.json`、`分类清单.md`。
- `分类确认.yaml`（首次自动生成，pending 文件逐条列出）。
- `00-总控/项目索引.md`（含投递区实际路径）。
- `01-建档与材料归集/原件指纹.json`（sha256，供 09 校验原件未改）。

## 退出码
0 完成；3 仍有待确认文件（必须先人工填写，重跑）；2 输入/参数错误。

## 规则要点
- 分类阈值：`auto_min_score 3.0`、`confidence_threshold 0.55`、`confidence_gap 0.15`。
- 低置信度、同分、无中心词命中 → 一律待确认，不自动落位。
- `已有成果/附表/修订版` 归 `04_成果报告/90_既有成果`，不进分类材料。
- 低空/OSGB 产物（`现状指标.json` 等）归 `10_低空指标`，定位是**指标证据**：只进指标表、附图与问题清单，作指标值来源；正文叙述仍靠文字材料，不因生成不出段落判失败。

## 已知限制
- 无 pdf 解析库时 pdf 只按文件名判定，正文关键词不参与打分。
- 同名文件会加父目录前缀区分；本项目不保留投递区子目录。
